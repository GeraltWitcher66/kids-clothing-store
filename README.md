# فروشگاه لباس کودک 🧸

طراحی ریسپانسیو (موبایل / تبلت / دسکتاپ) فروشگاه اینترنتی لباس کودک — **فقط فرانت‌اند**، بدون بک‌اند و بدون دیتابیس.

- فونت: **Vazirmatn** (محلی، در `assets/fonts`)
- استایل: **Tailwind CSS v4** (خروجی بیلد شده در `assets/css/style.css`)
- تصاویر: عکس‌های واقعی که به‌صورت لوکال داخل `assets/img` هستند و در ایران بدون فیلتر باز می‌شوند
- داده‌ها: تستی و ثابت (طراحی دیزاین)

## صفحات

| صفحه | فایل |
| --- | --- |
| صفحه اصلی | [index.html](index.html) |
| جزئیات محصول | [product.html](product.html) |
| سبد خرید | [cart.html](cart.html) |

همه‌ی مسیرها **نسبی** هستند، بنابراین سایت روی هاست ثابت و زیرپوشه هم درست کار می‌کند.

## اجرا روی سیستم خودتان

فایل‌ها را مستقیم باز کنید یا یک سرور استاتیک ساده بگذارید:

```bash
npx serve .
# یا
python3 -m http.server 8080
```

## تغییر استایل

```bash
npm install      # یک بار
npm run build    # ساخت assets/css/style.css
npm run dev      # واچ کردن تغییرات src/input.css
```

## انتشار روی GitHub Pages (لینک عمومی)

چون پروژه تماماً استاتیک است، هیچ دیتابیس یا سروری لازم نیست:

1. تغییرات را به‌origin push کنید.
2. در صفحه‌ی مخزن، به **Settings → Pages** بروید.
3. در بخش **Build and deployment** گزینه‌ی **Source: Deploy from a branch** را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و **Save** بزنید.
5. چند ثانیه بعد لینک زیر فعال می‌شود و می‌توانید آن را برای دیگران بفرستید:

```
https://<نام-کاربری-شما>.github.io/kids-clothing-store/
```

> فایل `.nojekyll` به‌منظور جلوگیری از پردازش Jekyll اضافه شده است.

## ساختار پوشه‌ها

```
├── index.html          صفحه اصلی
├── product.html        جزئیات محصول
├── cart.html           سبد خرید
├── assets/
│   ├── css/style.css   خروجی Tailwind (بیلد شده)
│   ├── fonts/          فونت وزیرمتن
│   ├── img/            عکس‌های محصولات
│   └── js/app.js       تعاملات دیزاین (افزودن به سبد، تب‌ها، …)
└── src/input.css       سورس Tailwind
```
